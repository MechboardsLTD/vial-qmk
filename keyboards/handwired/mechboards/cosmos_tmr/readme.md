# handwired/cosmo_ps2

![handwired/cosmo_ps2]

A cosmos generated gaming macropad with tmr analog stick.

* Keyboard Maintainer: [Mechboards](https://github.com/MechboardsLTD)
* Hardware Supported: rp2040_ce
* Hardware Availability: *Links to where you can find this hardware*

Make example for this keyboard (after setting up your build environment):

    qmk compile -kb handwired/mechboards/cosmos_tmr -km vial

Flashing example for this keyboard:

    qmk flash -kb handwired/mechboards/cosmos_tmr -km vial

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader by:

* **Bootmagic reset**: Hold down top left key and plug in the keyboard
